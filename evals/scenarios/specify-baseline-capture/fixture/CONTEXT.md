# Domain Context — stockroom

## Glossary

- Buyer — the person or client system that places an order. NOT a stock clerk, who manages stock levels.
- Order — a buyer's request for a quantity of one SKU, recorded once stock is reserved. NOT a reservation.
- Reservation — stock set aside for an order so nobody else can take it. NOT an order; it lives in inventory.
- SKU — the identifier of one stocked product. NOT a product listing.
